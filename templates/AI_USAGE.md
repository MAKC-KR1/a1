# AI 활용 기록

매 호출의 장문 보고 대신 중요한 작업·오류 수정 단위로 한 줄 기록한다. 도구의 원래 실행 이력은 유지한다.

| 작업·요구사항 ID | 모델 표시명 | AI에 맡긴 범위 | 사람이 확인·수정한 내용 | 검증 근거 | 표시된 토큰 사용량 |
|---|---|---|---|---|---|
| | | | | | 미제공 |

실제 표시된 사용량만 기록한다. 제공되지 않으면 미제공으로 남기고 추정량을 실측처럼 쓰지 않는다. 코드 생성량, 작업 성공률, 모델 비용과 토큰 수는 서로 다르다. 토큰을 아끼기 위해 실제 검증이나 필요한 오류 분석을 생략하지 않는다. 실패·재시도·중요한 수정도 기록한다.
