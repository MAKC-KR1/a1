# 사용한 외부 자료

실제로 사용한 자료만 기록한다. 최초에는 사용 기록 없음. 이 양식이 공개 상태나 사용 허용을 증명하는 것은 아니다.

| 공개 저장소 URL | 고정 커밋 SHA·태그 | 사용 파일·구간 | 라이선스 | 사용 목적·직접 변경한 내용 | 공개 확인 시각 |
|---|---|---|---|---|---|
| | | | | | |

자료를 사용하는 시점에 상세 가이드의 허용 범위와 공개 상태를 확인한다. 활용 저장소는 2차 예선 결과 통지 전까지 공개 상태로 유지되어야 한다. 타인 저장소의 공개 유지 여부를 보장할 수 없으므로 시험에서 허용하는 증빙·보관 방식은 상세 가이드에 따른다. 실제 문제·해답·담당자 대화·실행 기록을 자료 공개 저장소에 올리지는 않는다.
